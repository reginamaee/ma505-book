3.2 Warm-up

Determine the number of steps, what steps, and how many statements are in this SAS code.

data work.class_summary;
    set sashelp.class;
    BMI = (Weight / (Height**2)) * 703;
    if BMI >= 25 then Category = "Overweight";
    else Category = "Normal";
run;

proc sort data=work.class_summary;
    by descending BMI;
run;

proc print data=work.class_summary label;
    var Name Age Height Weight BMI Category;
    label BMI = "Body Mass Index"
          Category = "Weight Category";
    title "BMI Summary from SASHELP.CLASS";
run;
3 steps: 1 DATA step (lines 1–6), then 2 PROC steps: PROC SORT and PROC PRINT.
14 statements: 6 in the DATA step, 3 in PROC SORT, 5 in PROC PRINT.
The label statement spans two lines but is one statement: a statement ends at the semicolon, not at the end of the line.

3.3 Exploring data with PROCedures

Four procedures for a first look at any table: PRINT, MEANS, UNIVARIATE, and FREQ.

/* prints n rows for the listed columns */
proc print data=input-table(obs=n);
    var col-name(s);
run;

/* summary statistics for the listed columns */
proc means data=input-table;
    var col-name(s);
run;

/* summary statistics, with more about the distribution */
proc univariate data=input-table;
    var col-name(s);
run;

/* frequency table for each listed column */
proc freq data=input-table;
    tables col-name(s);
run;

3.4 PROC PRINT

Lists the rows of a table. (obs=10) keeps the first 10 rows; var picks the columns.

/* print the first 10 observations of the sashelp.cars table */

Reading the output

  • Skewness (1.25) tells us if the data is lopsided. 0 means symmetric. A positive value means a long tail to the right (a few really high values), and a negative value means a long tail to the left. Anything past ±1 is pretty skewed, so highway MPG is skewed right. Notice the mean (26.84) is a bit higher than the median (26).
  • Kurtosis (6.05) tells us how heavy the tails are compared to a normal bell curve (normal = 0). A positive value means more extreme values than we’d expect, so a 6 means we probably have some outliers.
  • Tests for Location (Mu0=0) test whether the center of the data is 0. Student’s t tests the mean (t = mean ÷ std error = 96.7). Sign and Signed Rank test the median and don’t assume the data is normal. All the p-values are below .0001, so we reject that the average MPG is 0, which we already knew! To test something useful, change the value with mu0=: proc univariate data=sashelp.cars mu0=25; tests whether the average is different from 25.

3.10 ODS: the Output Delivery System

ODS controls the type and format of the output your SAS code produces: how SAS displays and saves results.

  • ods trace on; writes the name of every output table to the log.
  • ods select table-name; keeps only that table in the results.

Exercise: use ods trace and ods select to output only the Extreme Observations table for Damage. Start here, then check the log:

libname ma505 "~";    /* ~ is your home folder; skip if your autoexec does this */

ods trace on;
proc univariate data=ma505.ow_stats;
    var Damage;
run;
/* the log lists "Name: ExtremeObs" for the Extreme Observations table */
ods trace off;

ods select ExtremeObs;
proc univariate data=ma505.ow_stats;
    var Damage;
run;

3.11 Filtering rows with WHERE

PROC procedure-name … ;
    WHERE expression;
RUN;

Works in PROC PRINT, MEANS, FREQ, and UNIVARIATE: the procedure only uses rows where the expression is true.

Operator Symbol Mnemonic
Equals = EQ
Not equal ^= or ~= NE
Greater than > GT
Less than < LT
Greater than or equal to >= GE
Less than or equal to <= LE

3.12 More WHERE operators

AND / OR: combine expressions 
proc print data=sashelp.cars;
    where Type = "SUV" and MSRP <= 30000;
run;
IN / NOT IN: match any value in a list 
proc print data=sashelp.cars;
    where Type in ("SUV", "Truck");
run;
IS MISSING / IS NOT MISSING 
proc print data=sashelp.cars;
    where Cylinders is missing;
run;
BETWEEN … AND: an inclusive range 
proc print data=sashelp.cars;
    where MSRP between 36000 and 50000;
run;
Dates: use a SAS date constant (Day 2) 
proc print data=sashelp.stocks;
    where Date > "01NOV2005"d;
run;

Character values are case-sensitive: "suv" does not match "SUV".

3.15 SAS macro variables

A macro variable is a placeholder: a name that stores a value you can reuse throughout a program. It makes code dynamic, reusable, and flexible: change the value once, and every place that uses it changes too.

proc print data=sashelp.cars;
    where Make = "Kia";
    var Type Make Model MSRP;
run;

proc freq data=sashelp.cars;
    where Make = "Kia";
    tables Origin;
run;
/* set a macro variable */
%let CarMake = Kia;

proc print data=sashelp.cars;
    where Make = "&CarMake";
    var Type Make Model MSRP;
run;

proc freq data=sashelp.cars;
    where Make = "&CarMake";
    tables Origin;
run;

%let creates it; & uses it. Use double quotes: "&CarMake" works, '&CarMake' does not.

3.17 Exercise

Use ma505.ow_stats:

  1. For Player 1, in the maps Busan, Nepal, Junkertown, and Oasis, find:
    1. the average number of eliminations and deaths
    2. the top 5 values for damage
  2. Do the same for Player 2.

Hint: a macro variable means you only change one line for Player 2.

libname ma505 "~";    /* ~ is your home folder; skip if your autoexec does this */

%let player = player1;    /* change to player2 and re-run */
%let maps = "Busan", "Nepal", "Junkertown", "Oasis";

/* a. average eliminations and deaths */
proc means data=ma505.ow_stats mean;
    where Player = "&player" and Map in (&maps);
    var Elimination Deaths;
run;

/* b. top 5 damage values: just the Extreme Observations table */
ods select ExtremeObs;
proc univariate data=ma505.ow_stats;
    where Player = "&player" and Map in (&maps);
